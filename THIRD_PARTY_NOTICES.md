## Fetched at install time (not redistributed)

### sherpa-onnx / sherpa-onnx-node

- License: Apache-2.0
- Purpose: local speech recognition and voice activity detection runtime.

### SenseVoiceSmall (int8) model

- Source: `csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17` on Hugging Face
- Downloaded by the installer with size and SHA-256 verification; see the upstream model

### Silero VAD

- Source: `csukuangfj/vad` on Hugging Face
- License: see upstream repository.

### ffmpeg

- License: LGPL-2.1+ or GPL-2.0+ depending on the build
- Purpose: microphone capture (DirectShow) and mp3 → wav conversion.
- The installer copies the ffmpeg binary that ships with DeepSeek Harness, or the user
  supplies their own via `config.json`.

### edge-tts

- License: GPL-3.0

- Not linked into this project's code; distributed as an independent program.

## Design inspiration

The floating orb's interaction language (cursor-following gaze, blinks, thinking saccades,
voice-reactive halo) is inspired by the SmoothUI components
[AI Orb Face](https://smoothui.dev/docs/components/ai-orb-face) and
[Siri Orb](https://smoothui.dev/docs/components/siri-orb). The implementation here is
original GDI+ code for a WinForms overlay; no code from those components is included.
